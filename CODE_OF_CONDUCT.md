# Code of Conduct

Parley is a small project with a simple standard: be professional, be
specific, and argue about artifacts.

- **Be welcoming.** Newcomers to GNU Smalltalk, to package managers,
  or to this codebase are the audience the project exists for.
  Questions are contributions.
- **Critique work, not people.** A defect report names a file, an
  input and an observed behavior. A review names the code. Neither
  names character.
- **No harassment.** Insults, discrimination, sexualized language,
  sustained disruption, and publishing others' private information
  are out, everywhere the project convenes — issues, pull requests,
  reviews and any affiliated space.
- **Disagree with evidence.** This repository settles design
  arguments with probes, laws and recorded decisions; discussions are
  expected to do the same. "It is ruled in the decision log" is an
  answer; "because I said so" is not.

Violations can be reported privately to the maintainer through
GitHub. Reports are handled confidentially; outcomes range from a
conversation to removal from project spaces, at the maintainer's
judgment and proportionate to the harm.
