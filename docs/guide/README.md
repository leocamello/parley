# Parley user guide

Start with the [sixty-second walk](../../README.md#the-sixty-second-walk): edit a library beside its consumer and run the new code without publishing. These pages explain the rest of the workflow for GNU Smalltalk 3.2.5.

| Page | Purpose |
| --- | --- |
| [Guide index](README.md) | Choose a task and find its instructions |
| [Installing](installing.md) | Check prerequisites and put Parley on your PATH |
| [Configuration](configuration.md) | Select an index through flags, environment or a project file |
| [Running code](running-code.md) | Load installed packages, run scripts and handle exit codes |
| [Publishing](publishing.md) | Build an immutable release in a flat or sparse index |
| [Developing two packages](developing-two-packages.md) | Work with sibling packages, development dependencies and lock modes |
| [Troubleshooting](troubleshooting.md) | Read diagnoses and repair manifests, files and project state |

For implementation contracts, read the [design specifications](../design/README.md). The [roadmap](../roadmap.md) records what is deferred and why; the [sprint record](../sprints/) records what shipped.
